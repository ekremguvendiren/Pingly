# Pingly - Advanced Network Diagnostics

## Short Description (GitHub About)
The ultimate network diagnostic tool for gamers and power users. Built with Tauri v2, Rust, and React, Pingly provides real-time game latency monitoring, accurate speed tests, and DNS benchmarking in a privacy-focused, modern interface.

## Key Features
- 🚀 **High-Performance Speed Test**: Measure accurate download, upload, ping, jitter, and packet loss.
- 🎮 **Gamer Zone**: Real-time latency checks for popular games like League of Legends, Valorant, CS2, Overwatch 2, and more.
- 🌐 **DNS Benchmark**: Compare your current DNS against top providers (Cloudflare, Google, OpenDNS) to find the fastest connection.
- 🛡️ **Privacy First**: Streamer Mode hides your IP, ISP, and location details with a single click.
- ⚡ **Native Performance**: Built on the lightweight Tauri v2 architecture for minimal resource usage.
- 🎨 **Modern Design**: Sleek, dark-mode interface powered by TailwindCSS and Framer Motion.
